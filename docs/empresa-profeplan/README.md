# Empresa ProfePlan

Este diretório é a porta de entrada da arquitetura documental-mãe da **EMPRESA PROFEPLAN**.

## Comece aqui

1. Leia o [`MASTER-BLUEPRINT.md`](./MASTER-BLUEPRINT.md) para compreender identidade operacional, arquitetura global, domínios A–M, fontes de verdade e governança.
2. Use [`blueprints/`](./blueprints/README.md) para localizar os blueprints especializados de cada domínio.
3. Use [`projects/`](./projects/README.md) para localizar iniciativas temporárias de execução vinculadas a um domínio.
4. Para inicializar uma nova pessoa, conversa ou agente, consulte também o [`ProfePlan Continuity Pack`](../profeplan-continuity/README.md).

## Limites desta camada

Esta estrutura organiza a empresa, o produto e suas fábricas. Ela não substitui código, schemas, ADRs, contratos, políticas, evidências, checkpoints ou documentação especializada.

- `MASTER-BLUEPRINT.md` define o mapa institucional estável e as regras de relação entre domínios.
- `docs/profeplan-continuity/` fornece bootstrap e continuidade transversal.
- `blueprints/` abrigará contratos duráveis por domínio.
- `projects/` abrigará iniciativas com objetivo, responsável, estado e critério de encerramento.

Nesta etapa, nenhum documento existente foi movido, renomeado ou apagado. Os domínios A–M estão registrados no Master Blueprint, mas seus blueprints detalhados serão criados somente quando houver escopo e fonte canônica suficientes.
