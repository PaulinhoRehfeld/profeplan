# Blueprints dos domínios

Este diretório receberá os blueprints duráveis dos domínios A–M registrados no [`MASTER-BLUEPRINT.md`](../MASTER-BLUEPRINT.md).

Nesta etapa não há placeholders individuais. Um blueprint será criado quando seu domínio tiver propósito, fronteiras, responsável, dependências e fontes de verdade suficientemente definidos. Até lá, o registro A–M do Master Blueprint é o índice oficial.

Documentação especializada já existente continua em seu local atual e deve ser referenciada, não movida ou duplicada.
