# F — Marketing & Vendas — Porta de Entrada

**Status:** implantação urgente

## Objetivo

Converter valor real do ProfePlan em aquisição, vendas e receita recorrente com comunicação sustentada por evidências do produto.

## Primeiros documentos

- `PRODUCT-EVIDENCE-PACK.md` — estrutura de evidências visuais e funcionais.
- `TRUTH-MATRIX.md` — matriz de status e comunicação permitida por funcionalidade.
- `CONTENT-PERMISSIONS.md` — regras para demonstração e divulgação.

## Regra comercial

Não esperar todas as fábricas ficarem prontas para vender o que já funciona. Também não vender roadmap como funcionalidade disponível.

## Fluxo

```text
produto real
→ evidência
→ mensagem verificável
→ campanha/oferta
→ conversão
→ receita
→ feedback
→ melhoria de produto
```

## Integrações prioritárias

- Aplicativo ProfePlan;
- Site/SaaS/UX;
- Stripe/checkout;
- Empresa/PUCTec;
- CRM futuro somente quando necessário.
