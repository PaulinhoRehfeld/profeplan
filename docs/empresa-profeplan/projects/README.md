# Projetos da Empresa ProfePlan

Este diretório receberá registros de iniciativas temporárias vinculadas aos domínios A–M.

Cada projeto deverá declarar domínio líder, objetivo, entregáveis, responsável, status, dependências, riscos, decisões, evidências e critério de encerramento. Uma iniciativa não se torna fonte de verdade transversal apenas por envolver vários domínios.

Projetos existentes permanecem em seus locais atuais nesta etapa. Migrações futuras exigirão inventário, mapa de referências e decisão explícita, sem apagar histórico.
