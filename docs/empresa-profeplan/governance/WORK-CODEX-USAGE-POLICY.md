# EMPRESA PROFEPLAN — Work/Codex Usage Policy

## Objetivo

Reduzir consumo de créditos quando ChatGPT + GitHub forem suficientes.

## Usar ChatGPT + GitHub para

- inspeção remota de código/documentos;
- criação de branches e Draft PRs;
- documentação;
- pequenas alterações de código verificáveis por CI;
- revisão de diffs, PRs e checks;
- planejamento e governança.

## Reservar Work/Codex para

- inspeção administrativa ao vivo não exposta pelo conector;
- operações locais que dependam do PDF governado fora do Git;
- execução de testes reais com arquivos privados;
- Vercel/ambiente quando interação direta for indispensável;
- transferência de repositório e reconciliação local;
- tarefas que exijam terminal/clone/ambiente local específico.

## Regra

Antes de usar Work/Codex, verificar se a mesma ação pode ser concluída por GitHub/CI sem perda de segurança ou evidência.
